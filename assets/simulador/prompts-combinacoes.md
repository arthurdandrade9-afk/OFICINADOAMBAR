# Prompts — Simulador de Combinações (15 imagens)

> O simulador em `site/index.html` (seção "Simule sua combinação") busca automaticamente o arquivo certo pelo nome — é só salvar cada imagem gerada com o nome exato abaixo em `site/assets/simulador/`. Assim que o arquivo existir, o placeholder vira imagem sozinho (mesmo comportamento dos outros placeholders do site).

## Bloco de estilo fixo (cole em todo prompt, no final)

```
Foto realista tirada com câmera de smartphone Android (tipo Samsung Galaxy ou Google
Pixel), com processamento HDR automático: contraste e saturação um pouco mais "punchy"
que iPhone, leve nitidez digital perceptível de perto. NÃO é renderização 3D, NÃO é
foto de banco de imagens perfeita demais. Ângulo levemente imperfeito, como foto rápida
de celular, não still de estúdio. Luz natural. Sem texto, sem logo, sem marca d'água.
```

## Exemplo de prompt completo (primeira linha da tabela)

```
Foto realista de uma barra de sabonete artesanal marmorizado em tons de roxo/branco,
com um pequeno símbolo de lua crescente gravado suavemente no topo, sobre uma mesa de
madeira clara perto de uma janela.
[+ bloco de estilo fixo acima]
```

Repita trocando só a primeira frase (a "ideia visual" da tabela) pra cada uma das 15.
